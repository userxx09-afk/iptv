# iptv

Basic repository for IPTV project.

This repository contains the project source code. To upload your code, either push from your local machine or use the included upload script.

How to upload from your machine:

1. Clone the repo:

   git clone https://github.com/userxx09-afk/iptv.git
2. Copy your project files into the cloned directory.
3. Commit and push:

   git add .
   git commit -m "Add project files"
   git push origin main

Or use the included helper script:

   ./upload.sh "Your commit message"

If you need a different license or .gitignore tailored to your language, tell me which language(s) and I'll update them.
